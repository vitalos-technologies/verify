# Vitalos Verify: status

## Summary
Vitalos Verify is a multi-tenant identity-verification platform, sold on its own and used by Vitalos Workforce through the same public API. It is a pre-pilot prototype on synthetic data: tenancy, applicant journey, review console, deletion, sealed evidence and a usage ledger exist, but the only provider is a mock and nothing is deployed. Progress depends on choosing a supplier and setting up hosting.
